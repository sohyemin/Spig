# SPig

> 친구를 사귀면서 언어도 함께 학습하고 싶은 사람들을 위한 화상채팅 서비스

## 1. 프로젝트 소개

**SPig**는 외국어로 대화할 기회를 만들고, 실제 대화를 통해 자연스럽게 언어를 학습할 수 있도록 돕는 화상채팅 서비스입니다.

프로젝트 이름은 돼지를 의미하는 `Pig`와 언어 말하기를 의미하는 `Speak`의 이미지를 결합한 이름입니다.

> 돼지처럼 배부르게 언어를 학습하고, 언어 학습의 마스터가 되자.

SPig에서는 새로운 외국인 사용자와 대화할 수도 있고, 이미 알고 지내는 외국인 친구와 대화하기 위한 개인 화상채팅방을 만들 수도 있습니다.

단순히 사람을 연결하는 화상채팅 서비스를 넘어, 사용자가 대화 과정에서 외국어를 사용하고 복습할 수 있도록 돕는 것을 목표로 합니다.

---

## 2. 프로젝트 목표

외국어를 공부하더라도 실제로 외국어를 사용해 대화할 기회를 찾기는 어렵습니다.

기존 화상채팅 서비스는 대화 자체에는 적합하지만, 사용자가 대화 중 사용한 표현을 기록하거나 모르는 단어를 학습할 수 있는 기능은 부족합니다.

SPig는 화상채팅과 언어 학습 기능을 결합해 다음과 같은 경험을 제공하고자 합니다.

* 외국어를 사용하는 사람과 새로운 관계를 만든다.
* 외국인 친구와 편하게 대화할 수 있는 공간을 제공한다.
* 대화 중 모르는 단어나 표현을 바로 검색한다.
* 자신이 사용한 외국어 표현을 기록하고 복습한다.
* AI의 긍정적인 피드백을 통해 말하기 자신감을 얻는다.

## 3. 주요 사용자

* 외국인 친구를 사귀고 싶은 사용자
* 외국어 회화 경험을 쌓고 싶은 사용자
* 이미 알고 있는 외국인 친구와 화상 대화를 하고 싶은 사용자
* 시험 공부뿐만 아니라 실제 대화를 통해 언어를 학습하고 싶은 사용자
* 외국어를 말할 때 자신감이 부족한 사용자

---

## 4. 핵심 사용자 흐름

### 새로운 사용자와 대화하기

```text
회원가입 및 로그인
→ 언어 학습 프로필 작성
→ 대화 상대 탐색
→ 대화방 입장
→ 화상채팅 진행
→ AI를 통한 표현 검색 및 기록
→ 대화 종료 후 피드백 확인
```

### 외국인 친구와 대화하기

```text
회원가입 및 로그인
→ 개인 대화방 생성
→ 초대 링크 또는 방 정보를 친구에게 전달
→ 친구가 대화방에 입장
→ 화상채팅 진행
→ 대화 기록 및 학습 내용 확인
```

## 6. AI 챗봇의 역할

SPig의 AI 챗봇은 사용자의 문법 오류를 지적하는 것에만 집중하지 않습니다.

사용자가 실제 대화에서 외국어를 계속 사용할 수 있도록 돕는 **언어 학습 보조자** 역할을 합니다.

### 6.1 사용한 언어 기록

화상채팅 중 사용자가 작성하거나 말한 외국어 문장을 기록합니다.

기록된 문장은 대화가 끝난 뒤 다시 확인하거나 복습 자료로 활용할 수 있습니다.

```text
사용자 발화 또는 채팅
→ 외국어 문장 기록
→ 대화별 학습 기록 저장
→ 대화 종료 후 조회
```

### 6.2 단어와 표현 검색

사용자는 대화 중 모르는 단어나 표현을 AI 챗봇에게 질문할 수 있습니다.

예시:

```text
“요즘 빠져 있다”를 일본어로 어떻게 말해?
```

AI 챗봇은 다음과 같은 정보를 제공합니다.

* 단어 또는 표현
* 의미
* 간단한 설명
* 사용 예문
* 대화 상황에 적합한 표현

검색한 표현은 이후 복습할 수 있도록 저장할 수 있습니다.

### 6.3 긍정적인 피드백

사용자의 외국어 사용에서 잘한 점을 찾아 긍정적인 피드백을 제공합니다.

예시:

```text
오늘 대화에서 과거형 표현을 자연스럽게 사용했어요.

모르는 단어가 있었지만 다른 표현으로 설명하며 대화를 이어간 점이 좋았습니다.

오늘 새롭게 사용한 표현은 세 개입니다.
```

AI는 사용자의 모든 문장을 부정적으로 평가하거나 과도하게 교정하지 않습니다.

잘한 점을 먼저 알려주고, 필요한 경우에만 개선할 표현을 함께 제시합니다.

```text
잘한 점
→ 새롭게 사용한 표현
→ 자연스럽게 대화를 이어간 부분
→ 개선할 표현
→ 다음 대화에서 사용할 수 있는 표현
```

## 7. AI 학습 기능의 방향

AI 답변은 사용자의 언어 수준과 학습 목적을 고려해야 합니다.

### 초급 사용자

* 쉬운 단어로 설명
* 짧은 예문 제공
* 실수를 지나치게 많이 지적하지 않음
* 대화를 이어갈 수 있도록 격려

### 중급 사용자

* 문법과 표현 차이 설명
* 자연스러운 대체 표현 제공
* 대화 상황에 맞는 예문 제공

### 고급 사용자

* 표현의 세부적인 뉘앙스 설명
* 비슷한 표현 비교
* 상황과 관계에 따른 표현 차이 안내

## 9. 1주차 개발 목표

1주차에는 전체 화상채팅 기능보다 AI 학습 기능의 기반을 먼저 구현
### 구현 목표

* Spring AI를 이용한 LLM 연결
* 언어 학습 질문 API 설계
* PostgreSQL 기반 학습 데이터 저장
* VectorDB를 이용한 언어 자료 검색
* 스케줄러를 이용한 학습 데이터 임베딩
* 검색한 자료를 기반으로 답변하는 RAG 구성
* 근거가 부족한 답변을 제한하는 방법 조사

### 1주차 예상 동작

```text
언어 학습 자료 DB 저장
→ 스케줄러가 새로운 자료 확인
→ 학습 자료 임베딩
→ 사용자가 단어나 표현 질문
→ 관련 학습 자료 검색
→ AI가 검색 자료를 참고해 답변
→ 사용한 자료와 답변 반환
```
